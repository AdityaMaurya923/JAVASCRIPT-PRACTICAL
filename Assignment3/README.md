## 4. Theory

The following concepts are used in this experiment:

**1. Conditions:**
`if`, `else if` and `else` run only one block depending on which condition is true first.

**2. for loop:**
`for (start; condition; step)` repeats a block a known number of times.

**3. while loop:**
`while (condition)` repeats a block as long as the condition is true.

## 5. Algorithm / Procedure

### Task 1: Grade using if / else if / else

4. Else if marks >= 60 print `Grade B`.

### Task 2: for loop 1 to 5

### Task 3: while loop total

3. While `total` is not more than 20, add `i` to `total` and add 1 to `i`.
4. Print `total`.
5. Stop.
