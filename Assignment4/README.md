## 4. Theory

The following concepts are used in this experiment:

**1. Function with return:**
A function groups code under a name. `return` sends a value back to the caller.

**2. Arrow function:**
A shorter way to write a function: `const square = (n) => n * n;`

**3. Default parameter:**
A parameter can have a default value that is used when no argument is given: `function f(a, rate = 0.18)`.
