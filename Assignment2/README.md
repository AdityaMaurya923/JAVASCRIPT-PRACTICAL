## 4. Theory

The following concepts are used in this experiment:

**1. Arithmetic Operators:**

- `+` : Addition
- `-` : Subtraction
- `*` : Multiplication
- `/` : Division

**2. Type Conversion:**

- `Number("12")` converts text to a number.
- `String(7)` converts a number to text.
- The `+` operator joins two texts (concatenation), so `"7" + "3"` gives `"73"`.

**3. if / else if:**
`if` and `else if` choose which block of code runs based on a condition.
