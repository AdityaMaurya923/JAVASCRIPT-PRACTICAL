## 4. Theory

The following concepts are used in this experiment:

**1. Object:**
An object stores data as `key: value` pairs. Properties are read with `obj.name` and changed with `obj.marks = 81`.

**2. Array destructuring:**
`const [first, second] = array;` takes values by position.

**3. Object destructuring:**
`const { name, roll } = obj;` takes values by property name.
