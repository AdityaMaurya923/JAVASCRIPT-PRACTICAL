## 4. Theory

The following concepts are used in this experiment:

**1. console.log():**
`console.log()` prints a value in the console (browser DevTools or the terminal when run with Node).

**2. Variables:**

- `const` : declares a value that cannot be reassigned.
- `let` : declares a value that can be changed later.

**3. typeof operator:**
`typeof` returns the type of a value as text, such as `"string"`, `"number"` or `"boolean"`.

**4. script tag:**
A `<script>` tag placed inside the body of an HTML page runs JavaScript when the page loads.
