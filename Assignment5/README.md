## 4. Theory

The following concepts are used in this experiment:

**1. Array:**
An array stores many values in order. Items are read by index starting from 0, and `length` gives the number of items.

**2. forEach:**
`forEach` runs a function once for every item.

**3. filter:**
`filter` returns a new array with only the items for which the function returns true.

**4. Nested array:**
An array inside an array is read with two indexes: `grid[row][column]`.
